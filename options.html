Settings

Timing and limits

Each batch stops at this number. Default 1000. Every 40 invites, the run pauses for one minute.

A run also stops if today's total hits the daily limit. Raise this if it is lower than the run limit.

On by default. When Max reactions this run is reached, the scan pauses 20 minutes, then starts inviting again on that same post. It keeps doing that until the Invite buttons run out, you press Stop, or the daily limit is hit. Leave the reactions window open. Turn this off for a hard stop at the limit.

Start Invite Scan only. After each post or Facebook comment thread, it waits 20 minutes before opening the next one. That pause is there so Meta is less likely to time out the invite feature. Scan Current Post does not wait. Turn this off only if you accept that risk. Stop still ends the wait.

Behavior

Default is skip. A reaction row with a Follow button is not an Invite, so it is left alone. Invite buttons are still clicked. Choose the second option only if you also want Follow clicked.
